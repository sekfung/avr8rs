# avr8rs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the complete avr8js 0.21.1 core library to safe Rust and pass all 347 upstream unit tests as native `cargo test` tests.

**Architecture:** `Cpu` and every peripheral are cheap cloneable handles over `Rc<RefCell<State>>`. Register hooks, clock events, and callbacks follow the upstream object graph; callbacks that can re-enter the simulator receive `&mut CpuState` so no second `RefCell` borrow is needed. The instruction loop holds one CPU borrow per batch, and clock events use stable `ClockEventId` tokens so recurring timers do not allocate closures.

**Tech Stack:** Rust stable, edition 2021, standard library only, `cargo test`, `cargo clippy`, `rustfmt`.

**Spec:** `docs/superpowers/specs/2026-11-11-avr8rs-design.md`

## Global Constraints

- Upstream reference is `wokwi/avr8js` tag `0.21.1`, commit `bee6f0a94e0e27786f6bc21aee3c775849fb50fd`, MIT licensed.
- Deliverable is a library crate only. No CLI, Intel HEX loader, demo UI, board wiring, or JS/WASM bindings.
- Crate name is `avr8rs`. Rust edition is 2021. There are no runtime dependencies.
- `src/lib.rs` starts with `#![forbid(unsafe_code)]`. No `unsafe` blocks anywhere.
- The final `cargo test --lib` result must be exactly `347 passed`.
- Per-module test counts are fixed: cpu 6, instruction 97, interrupt 2, adc 2, clock 8, eeprom 10, gpio 22, spi 11, timer-attiny 10, timer 55, twi 7, usart 28, watchdog 6, assembler 83.
- Public naming follows the spec map: `CPU` → `Cpu`, `avrInstruction` → `avr_instruction`, `AVRADC` → `Adc`, `adcConfig` → `adc_config()`, `AVRIOPort` → `IoPort`, `AVRTimer` → `Timer`, `AVRTWI` → `Twi`, `AVRUSART` → `Usart`, `AVRUSI` → `Usi`, `AVRWatchdog` → `Watchdog`.
- Every config is returned by an owned-value function such as `port_b_config()`; enum discriminants match upstream numeric values where tests observe them.
- Callbacks that may drive the simulation receive `&mut CpuState`. Notification-only callbacks keep upstream argument lists.
- Clock events are addressed by `ClockEventId`. GPIO listeners are removed by `ListenerId`.
- The assembler and test support compile under `cfg(test)` only and are not part of the public API.
- README examples are plain code blocks, not doctests, so the unit-test count stays exactly 347.

- [ ] **Step 4: Implement the parser and directives**

In `src/assembler/parser.rs`, implement the upstream pass-one rules exactly:

- Trim each line; skip empty lines.
- Strip comments starting at the first `#` or `;`.
- Match a leading `label:` where the label is one or more word characters.
- Split the remaining text into mnemonic and zero, one, or two comma-separated operands.
- Accept decimal and `0x` hexadecimal numbers with `parse_int`.
- Implement `_REPLACE name value`, `_LOC address`, and `_IW word`.
- Track byte offsets; `_LOC` must be even; `_IW` emits one word.
- Record parse errors with the upstream line index convention `Line {idx}: {message}`.

fn ldi(a: &str, b: &str) -> Encoded {
    let d = dest_r(a, 16, 31) & 0xf0;
    let k = const_value(b, 0, 255);
    Encoded::Words(vec![0xe000 | d | ((k & 0xf0) << 4) | (k & 0x0f)])

- [ ] **Step 4: Implement clock events and interrupts**

`avr_interrupt` pushes `pc` onto the stack, clears the global interrupt flag, sets `pc` to the vector address, and uses two cycles, matching upstream.
